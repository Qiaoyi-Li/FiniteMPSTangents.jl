# FiniteMPSTangents

[![Stable documentation](https://img.shields.io/badge/docs-stable-blue.svg)](https://Qiaoyi-Li.github.io/FiniteMPSTangents.jl/stable/)
[![Development documentation](https://img.shields.io/badge/docs-dev-blue.svg)](https://Qiaoyi-Li.github.io/FiniteMPSTangents.jl/dev/)

FiniteMPSTangents.jl provides finite-MPS tangent vectors, their gauge
orthogonalization and linear algebra, and projected multiplication by sparse
matrix-product operators. It builds on
[FiniteMPS.jl](https://github.com/Qiaoyi-Li/FiniteMPS.jl).

## Installation

This package is not yet registered. During development, install it from its
repository:

```julia
using Pkg
Pkg.add(url="https://github.com/Qiaoyi-Li/FiniteMPSTangents.jl")
```
